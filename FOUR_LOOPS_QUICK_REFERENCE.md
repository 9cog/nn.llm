# The Four Learning Loops: Quick Reference Card

## One-Page Summary for Rapid Decision-Making

---

## The Loops at a Glance

| Loop | Core Question | Focus | Outcome | When to Use |
|------|---------------|-------|---------|-------------|
| **1. Single** | *How?* | Actions & efficiency | Working solution | Need to solve problems |
| **2. Double** | *Why?* | Values & assumptions | Aligned priorities | Solutions feel wrong |
| **3. Triple** | *How do we improve?* | Meta-learning process | Better learning capacity | Want to learn faster |
| **4. Quadruple** | *What is it?* | Epistemology & ontology | Paradigm shift | Hit fundamental limits |

---

## Quick Decision Tree

```
┌─ Need to FIX something?        → Loop 1 (Single-Loop)
├─ Feel MISALIGNED?               → Loop 2 (Double-Loop)
├─ Want to IMPROVE PROCESS?       → Loop 3 (Triple-Loop)
└─ Need PARADIGM SHIFT?           → Loop 4 (Quadruple-Loop)
```

---

## The Four Questions

### 🔧 Loop 1: Single-Loop (Technical)
**"How do I make this work?"**
- What needs to be done?
- How can I do it efficiently?
- Does it work correctly?

**Example**: "Implement RMSNorm for faster normalization"

---

### 🤔 Loop 2: Double-Loop (Values)  
**"Why am I doing this?"**
- What assumptions am I making?
- What values am I optimizing for?
- What trade-offs am I accepting?

**Example**: "Why do we value efficiency over interpretability?"

---

### 🎯 Loop 3: Triple-Loop (Meta-Learning)
**"How can I learn better?"**
- What patterns do I notice?
- How can I improve my learning process?
- What meta-skills am I developing?

**Example**: "What patterns across optimizations can improve future learning?"

---

### 🌀 Loop 4: Quadruple-Loop (Epistemology)
**"What is the nature of this?"**
- What paradigm am I operating in?
- What assumptions constrain my thinking?
- What would a fundamentally different approach look like?

**Example**: "What does 'normalization' reveal about the nature of representation?"

---

## Signs You Need Each Loop

### ⚠️ Loop 1 Signals
- ❌ Code doesn't work
- 🐌 Performance is poor
- 🎯 Clear problem to solve
- 📋 Specific task to complete

### ⚠️ Loop 2 Signals
- 😕 Success feels hollow
- 🔄 Optimizing wrong metrics
- 🤷 Asking "why are we doing this?"
- 💭 Values feel misaligned

### ⚠️ Loop 3 Signals  
- 🔁 Making same mistakes repeatedly
- 📚 Learning feels inefficient
- 🎓 Want to accelerate growth
- 📊 Noticing patterns across work

### ⚠️ Loop 4 Signals
- 🚧 Hitting fundamental walls
- 🌐 Current paradigm feels limiting
- 💡 Ready for breakthrough insights
- 🧠 Questioning nature of domain

---

## The Transformation Chain

```
Loop 1: Actions      →  Better code
Loop 2: Values       →  Better priorities  
Loop 3: Process      →  Better learning
Loop 4: Paradigm     →  Better understanding

Each level transforms everything below it.
```

## Time Allocation Guide

### Typical Balance (for most work)

| Loop | Daily | Weekly | Monthly | Quarterly |
|------|-------|--------|---------|-----------|
| 1 | 80% | 70% | 60% | 50% |
| 2 | 15% | 20% | 25% | 25% |
| 3 | 4% | 8% | 12% | 15% |
| 4 | 1% | 2% | 3% | 10% |

### Crisis Mode (hit a wall)
- **Jump immediately to higher loops**
- Loop 2 or 3 might reveal the real problem
- Loop 4 if truly paradigm-blocked

---

## Common Mistakes

### ❌ Too Much Loop 1
- **Result**: Busy but not effective
- **Fix**: Pause and question (Loop 2)

### ❌ Too Much Loop 2
- **Result**: Analysis paralysis
- **Fix**: Just act (Loop 1)

### ❌ Too Much Loop 3  
- **Result**: Meta-learning without learning
- **Fix**: Apply learning, not just study it

### ❌ Too Much Loop 4
- **Result**: Lost in philosophy
- **Fix**: Ground in practical action

## The Four Depths

```
Surface ────────────────────────────────> Depth

Loop 1:  Symptoms      (Fix the bug)
Loop 2:  Root Causes   (Why did bug occur?)  
Loop 3:  Systems       (How to prevent bugs?)
Loop 4:  Foundations   (What is "correctness"?)
```

## When Multiple Loops Apply

### Sequential Approach
1. Start with highest applicable loop
2. Work down through lower loops
3. Return up with insights

### Parallel Approach
- Keep all loops active mentally
- Switch between as needed
- Let insights from each inform others

## Essential Principles

### 1. **All Loops Matter**
Don't skip lower loops—they're essential

### 2. **Context Determines Loop**
Use the right tool for the job

### 3. **Loops Transform Each Other**  
Higher loops enrich lower loops

### 4. **Balance is Key**
Too much of any loop causes problems

### 5. **Wisdom is Integration**
Master all loops and move between them fluidly
